# ChainGraph demo video

Source of the product demo (`docs/media/demo.mp4`), built with [Remotion](https://www.remotion.dev).

```bash
npm install
npm run dev      # Remotion Studio: preview and edit
npm run render   # writes ../docs/media/demo.mp4
```

Screenshots used by the scenes live in `public/shots/` (captured from the app at 1920×1080 with the red accent).

Remotion is free for individuals and small teams; companies may need a license. See https://www.remotion.dev/license.
